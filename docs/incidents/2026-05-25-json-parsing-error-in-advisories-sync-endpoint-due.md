## Summary
JSON parsing error in advisories sync endpoint due to attempting to parse an object instead of a valid JSON string

## Root Cause
The POST /api/platform/advisories/sync endpoint is receiving a request body that contains an object being passed to JSON.parse() instead of a JSON string, causing SyntaxError when "[object Object]" is parsed

## Impact
1 user affected, advisory synchronization feature is broken preventing security updates from being fetched

## Resolution
1. Check the request body parsing in the advisories sync API route 2. Add proper type validation before JSON.parse() 3. Use req.json() instead of JSON.parse(req.body) if using fetch API 4. Add error handling with try-catch around JSON parsing operations 5. Log the actual request body type and content for debugging
